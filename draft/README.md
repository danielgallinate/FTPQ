# Draft — material previo

Archivo de trabajo **no oficial**. Todo lo generado antes de ordenar la raíz vive aquí.

## Contenido

| Item | Descripción |
|------|-------------|
| `documentacion/` | Handoff completo pasos 1–5, plataformas, ADRs |
| `.cursor/` | Rules y skills del handoff |
| `mocks/` | Fixtures SFTP/CSV/perfiles |
| `AGENTS.md` | Instrucciones agentes |
| `*.md`, `*.txt` | Docs sueltas del validator y handoff original |

## Uso

Copiar a la raíz **en orden**, no mover todo de golpe:

```bash
# Ejemplo paso 1
cp -R draft/documentacion/paso-01-entender documentacion/
```

No editar en `draft/` como fuente de verdad una vez copiado a la raíz.
